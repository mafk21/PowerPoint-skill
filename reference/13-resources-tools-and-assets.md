# 13 — Resources, Tools & Assets

The supply chain behind pro decks. Curated from the creator ecosystem (`09`)
and 2026 tool roundups. Prices/status are snapshots — verify before purchase.

## A. PowerPoint add-ins (force multipliers)

| Tool | Cost | Superpower | Notes |
|---|---|---|---|
| **BrightSlide** (BrightCarbon) — brightcarbon.com/brightslide | **Free** | Align/distribute/match-size at Adobe-grade precision, select-similar, animation stagger/copy, tidy grids | The consensus #1 free add-in; Windows-first (Mac version exists per vendor) |
| **think-cell** | ~$27/mo Suite (from ~$328/yr) | Waterfall/Gantt/Mekko charts w/ live Excel links, CAGR arrows, agenda automation | Consulting/finance standard (950K+ users); Win+Mac |
| **iSlide** | Freemium | Built-in template/icon/diagram libraries, one-click beautify | Popular with the template-shop crowd |
| **PPT Productivity** | from $179/yr | 800+ shortcut commands, slide library, proofing | Ex-MBB-built; Windows |
| **Power-user** | ~$99/yr | Ready business slides/maps, Excel linking, cleanup | Fast corporate decks |
| **Efficient Elements / Macabacus / UpSlide / empower / Templafy / SlideHub** | Pro/enterprise | Brand governance, slide libraries, template management | For teams re-building the same decks weekly |
| **Office Timeline (Lucen)** | Paid | Clean project timelines/Gantt from data | PM decks |
| **Pexels add-in** | Free | Stock photos inside PowerPoint | Licensing-safe imagery |
| **Plus AI / Claude & ChatGPT for PowerPoint add-ins** | ~$10–20/mo | Generate/edit *natively* in the file (masters & charts respected) | Native > exported-from-web (see §B) |

Rule: **BrightSlide first** (free), **think-cell** if data-dense consulting
work pays for it, library tools when a team shares decks.

## B. AI presentation tools (2026 state — read before recommending)

| Tool | Reality check |
|---|---|
| **MS Copilot in PowerPoint** | Native .pptx (no export problem), agentic editing GA since Apr 2026; needs M365 + Copilot license (~$18–30/user/mo). Best "AI inside the real tool." |
| **Gamma** | Fastest prompt→draft (free 400 credits). **PPTX export is the known weakness**: layouts flatten/shift, fonts substitute (~30% editable-text retention reported in independent tests), no slide master, recognizable "Gamma look". Fine for web-shared drafts, not final client .pptx. |
| **Beautiful.ai** | Strong brand-consistent auto-layouts, decent PPTX fidelity (~8.5/10 in tests); rigid templates; no free tier ($12+/mo). |
| **Canva (AI)** | Huge asset library, free tier real; effects sometimes flatten on PPTX export (~7/10). |
| **Plus AI** | Builds inside PowerPoint/Google Slides → native files; metered credits. |
| **Gemini in Google Slides** | Multi-slide generation (mid-2026, US-English first); some exports are image-per-slide — check editability. |
| **Prezi** | No meaningful PPTX export (3.5/10) — different medium entirely. |

**Critical positioning for this skill:** *no* AI deck tool creates real Morph
choreography, `!!` travelling elements, or PlacePlate-grade consistent
systems — they generate static approximations. Workflow: AI for ugly first
draft/outline → our generator/design system for the deliverable.

## E. Social/Video specs (decks → reels & carousels)

Design once at **1080×1920 (9:16)** for TikTok + Reels + Shorts; Instagram
*feed* carousels want **1080×1350 (4:5)** (all slides same ratio — never mix).

| Format | Spec | Deck settings |
|---|---|---|
| Reel/TikTok/Short video | 1080×1920 MP4 (H.264, 30 fps), ≤ ~60 s sweet spot (reels ≤3 min) | Slide size 7.5×13.333 in (portrait 9:16) *or* 16:9 deck letterboxed on brand bg; Export ▸ Video 1080p |
| Safe zones (video) | Keep key content in central ~15–70% height; bottom ~25% is caption/UI, right edge is buttons | Nothing critical in bottom quarter (stricter than the 10% stage rule) |
| IG carousel | 1080×1350, ≤20 slides (6–10 sweet) | Slide size 10.8×13.5 in; export slides as PNG |
| TikTok photo carousel | 1080×1920, 2–35 images, ≤20 MB each | as reel spec |
| YouTube/community, LinkedIn doc posts | 16:9 PDF or 1080×1080 | export PDF / PNG |

Workflow (PlacePlate formula, `08`): present/record the Morph deck →
Export MP4 → (optional) reframe 9:16 in CapCut/Premiere → caption formula +
hashtag spine → CTA link-in-bio. Morph decks are pre-animated content; that's
the entire trick of the genre.

## This repo's own tools

Beyond the generator and the QA gate, the repo ships a small toolchain in
`tools/` (all stdlib + python-pptx; BrandKit needs Pillow):

| Tool | What it does |
|---|---|
| `qa_deck.py` | Automated QA gate (Morph map, word budgets, type floors, notes) — must pass GREEN |
| `palette_lab.py` | One seed hex → full 7-role theme via color harmonies, auto-repaired to WCAG floors (ink 10:1, muted 4.5:1, accent 3:1); `--pack` installs 8 curated themes |
| `brandkit.py` | Logo/image → theme: median-cut palette, vivid-pixel recovery (antialias washout fix), BrandKit scoring favors highlight-usable saturated colors; `--also-dark` emits a dark sibling |
| `anatomy.py` | Any .pptx → report: canvas, Morph map, palette by painted area, text colors by char count, fonts, per-slide census — plus a guessed theme pinned to the deck's real bg/card (`--write NAME` saves it) |
| `draft.py` | Raw notes → spec (+ deck): headings, bullets, label:value data, numbered steps, quotes, stat lines, closing asks are auto-classified into slide types; original prose is preserved as speaker notes |
| `coach.py` | Speaker Coach: per-slide talk time from notes (~130 wpm), READING-RISK (script copies slide, word-overlap), THIN SCRIPT and NO SCRIPT flags, target-runtime trims, `--write-md` rehearsal cue cards |
| `wizard.py` | Creator Mode: goal + topic + claim → DB structure (recipe sequence → slide types) + DB-recommended theme + starter copy with coaching notes → built deck → QA verdict. Flags or `--interactive` |

All theme tools write `database/data/themes.json`; the generator merges it
over its built-ins, and `database/build_db.py` folds the same palettes into
the Monster Database (`query.py palettes`). One source of truth, three
consumers.
